# Tic Tac Toe Game

A modern implementation of the classic Tic Tac Toe game built with React and SCSS.

Live demo: https://emilia-burza-tic-tac-toe-game.netlify.app/

## Features

- Play against CPU or another player
- Choose between X and O marks
- Track game scores
- Responsive design that scales smoothly across all devices
- Hover states for interactive elements
- Modern UI with smooth animations
- Victory and tie state handling

## Technical Details

- Built with React
- Styled using SCSS with modular architecture
- Responsive design using media queries
- Custom components for:
  - Game board
  - Modal windows
  - Interactive buttons
  - Score tracking
- State management using React Context

## Game Modes

1. **VS CPU**: Challenge the computer in a single-player mode
2. **VS Player**: Play against a friend in two-player mode

## Design Features

- Custom shadows and inset effects
- Responsive scaling without breaking layout
- Consistent color scheme using SCSS variables
- Interactive hover states
- Smooth transitions and animations

## Development

This project uses:
- React for UI components
- SCSS for styling
- CSS Grid for game board layout
- Flexbox for responsive layouts
- CSS custom properties for theming

This is a solution to the Tic Tac Toe challenge on Frontend Mentor, implementing all required features and adding additional enhancements for better user experience.
